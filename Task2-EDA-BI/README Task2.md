# Exploratory Data Analysis & Business Intelligence Project

## Project Overview

This project demonstrates an end-to-end **Exploratory Data Analysis (EDA)** and **Business Intelligence** workflow using Python, SQL, and Excel. The objective was to analyze a sales dataset, uncover business insights, answer analytical questions through SQL, and build a professional dashboard for decision-making.

The project showcases data analysis, visualization, SQL querying, and dashboarding skills suitable for a **Data Analyst portfolio**.

---

## Objectives

* Perform descriptive and exploratory data analysis.
* Identify trends, patterns, and relationships in sales data.
* Answer business questions using SQL queries.
* Conduct multivariate and correlation analysis.
* Create a static executive dashboard for business reporting.
* Generate actionable business insights.

---

## Dataset

The dataset contains sales transaction records including product, category, customer, city, quantity, order date, and revenue-related fields.
